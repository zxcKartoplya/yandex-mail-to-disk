# Как настроить выгрузку вложений из Яндекс Почты на Яндекс Диск

Программа раз в день забирает вложения из новых писем и складывает их на ваш Яндекс Диск,
в папку «Вложения из почты», разложив по дням: `Вложения из почты/2026-09-24/Отчёт.pdf`.
Письма остаются в почте нетронутыми и не помечаются прочитанными.

## Что понадобится (5 минут)

### 1. Включить в Почте доступ для программ

1. Откройте Яндекс Почту → значок шестерёнки → **Все настройки** → **Почтовые программы**.
2. Поставьте галочку **«С сервера imap.yandex.ru по протоколу IMAP»**.
3. Ниже поставьте галочку **«Пароли приложений и OAuth-токены»**, если она есть.

### 2. Создать два пароля приложений

Это отдельные пароли только для этой программы. Ваш основной пароль от Яндекса программа не узнает.

1. Откройте <https://id.yandex.ru/security/app-passwords>.
2. Нажмите **«Создать пароль приложения»** → выберите **«Почта»** → придумайте название, например «Выгрузка».
   Скопируйте пароль — он показывается один раз. Вставьте его в программу, когда она попросит.
3. Ещё раз **«Создать пароль приложения»** → выберите **«Файлы»** (WebDAV).
   Этот пароль тоже понадобится программе.

## Первый запуск

**Windows.** Дважды щёлкните по файлу `YandexMailToDisk.exe`.
Если Windows покажет синее окно «Windows защитила ваш компьютер» — нажмите
**«Подробнее» → «Выполнить в любом случае»**. Так бывает со всеми программами без платной подписи.

**Mac.** Дважды щёлкните по файлу `YandexMailToDisk`. Если macOS напишет, что не может проверить
разработчика: откройте **Системные настройки → Конфиденциальность и безопасность**, внизу нажмите
**«Всё равно открыть»**, затем снова дважды щёлкните по файлу.

Дальше программа задаст пять вопросов:

1. адрес почты;
2. пароль приложения для Почты — **символы при вводе не видны, это нормально**. Вставить можно правой
   кнопкой мыши (Windows) или Cmd+V (Mac), затем Enter;
3. пароль приложения для Диска;
4. папка на Диске — можно просто нажать Enter;
5. время ежедневного запуска — можно просто нажать Enter (09:00).

Программа сама проверит пароли, сделает первую выгрузку за последние 7 дней и включит автозапуск.
После сообщения «Готово» окно можно закрыть. Исходный файл программы можно удалить или оставить —
она уже скопировала себя куда нужно.

## Как это работает потом

- Каждый день в выбранное время программа запускается сама.
  На Windows на несколько секунд появится чёрное окно — это она, закрывать не нужно.
- Если компьютер в это время был выключен — выгрузка пройдёт при следующем включении,
  ничего не потеряется.
- Спам, корзина, отправленные и черновики не выгружаются.
- Если файл с таким именем за этот день уже есть, новый сохранится как `Имя (2).pdf`.
  Одинаковые файлы повторно не загружаются.

## Если что-то пошло не так

Запустите программу двойным щелчком ещё раз. Откроется меню:

- **1 — Выгрузить сейчас** — сразу проверить почту;
- **2 — Изменить настройки** — если поменялись пароли;
- **3 — Открыть папку с журналом** — файл `log.txt` можно отправить тому, кто помогал с настройкой;
- **4 — Отключить автозапуск и удалить настройки**.

Частые причины ошибок:

- «Яндекс Почта не пустила» — неверный пароль приложения или не включён IMAP (см. пункт 1).
- «Яндекс Диск не принял пароль» — пароль для Диска создан не с типом «Файлы» или удалён.
- «На Яндекс Диске закончилось место» — освободите место на Диске.
